## 📝 Problem 2

### Problem Statement
Write a program to input two numbers and display their sum, difference, product, and quotient.

> 💡 **Note:** Division by zero should be handled carefully.

### Test Cases

#### Case 1
- **Input:** `10 2`
- **Output:** `Sum=12, Diff=8, Product=20, Quotient=5`

#### Case 2
- **Input:** `7 3`
