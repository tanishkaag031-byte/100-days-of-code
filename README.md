## 📝 Problem 17

### Problem Statement
Write a program to find the roots of a quadratic equation and categorize them.

### Test Cases

#### Case 1
- **Input:** `1 -3 2`
- **Output:** `Roots are real and different: 2, 1`

#### Case 2
- **Input:** `1 -2 1`
- **Output:** `Roots are real and same: 1`

#### Case 3
- **Input:** `1 2 5`
- **Output:** `Roots are complex`

## 📝 Problem 18

### Problem Statement
Write a program that accepts a percentage (0-100) and assigns a grade based on the following criteria: 
90-100: Grade A 
80-89: Grade B 
70-79: Grade C 
60-69: Grade D 
below 60: Grade F.

### Test Cases

#### Case 1
- **Input:** `95`
- **Output:** `Grade A`

#### Case 2
- **Input:** `82`
- **Output:** `Grade B`

#### Case 3
- **Input:** `68`
- **Output:** `Grade D`

#### Case 4
- **Input:** `50`
- **Output:** `Grade F`
