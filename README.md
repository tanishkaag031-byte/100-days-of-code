## 📝 Problem 77

### Problem Statement
Check if the elements on the diagonal of a matrix are distinct.

### Test Cases

#### Case 1
- **Input:**
  ```text
3 3
1 2 3
4 5 6
7 8 1
  ```
- **Output:** `False`

#### Case 2
- **Input:**
  ```text
3 3
1 2 3
4 5 6
7 8 9
  ```
- **Output:** `True`
