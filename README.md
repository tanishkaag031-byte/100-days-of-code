## 📝 Problem 131

### Problem Statement
Create an enumeration for days (SUNDAY to SATURDAY) and print each day with its integer value.

### Test Cases

#### Case 1
- **Input:** `No input`
- **Output:**
  ```text
SUNDAY = 0
MONDAY = 1
TUESDAY = 2
WEDNESDAY = 3
THURSDAY = 4
FRIDAY = 5
SATURDAY = 6
  ```
- **Explanation:** Each day in the enum is automatically assigned an integer starting from 0.
